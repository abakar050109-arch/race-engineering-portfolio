# Дорожная карта портфолио

Цель: к концу учёбы иметь портфолио, с которым берут в зарубежную команду GT3/GT4. Дальше — WEC / Formula E, потом F1.

Этот файл — не мечта, а очередь работ. Один проект за раз.

## Правило одного проекта

Не начинаю следующий проект, пока у текущего нет:

1. рабочего кода, который запускается одной командой;
2. README с разделом «Вывод» — не «вот график», а «вот что это значит для машины»;
3. коммита на GitHub.

Три пункта. Пока их нет — проект не закрыт, и двигаться дальше нельзя. Это защита от привычки бросать на 80%.

## Уровень 1 — база (сейчас, 1 курс)

### Проект 01. Разбиение сессии на круги и базовая телеметрия
**Задача:** из сырого CSV (200 Гц) получить круг, а не случайное окно; построить скорость, газ и тормоз по дистанции.

**Что освоить:** чтение MoTeC CSV, интегрирование скорости в дистанцию (`cumsum`), поиск границ круга, единицы измерения (м/с → км/ч), matplotlib.

**Готово, когда:** скрипт сам находит круги по дистанции и рисует три графика, а в README написано, сколько кругов найдено и какой из них лучший.

**Фраза для интервью:** «Я умею превратить сырой лог в круг и прочитать его по каналам — скорость, педали, передачи».

### Проект 02. Дельта времени
**Задача:** наложить два круга по дистанции и посчитать накопленную разницу времени.

**Что освоить:** интерполяция на общую сетку (`numpy.interp`), интегрирование разницы времён, чтение графика дельты.

**Готово, когда:** на графике видно, в каких поворотах время теряется и сколько именно.

**Фраза для интервью:** «Я вижу не просто "линии разошлись", а в какой точке и сколько секунд это стоит».

## Уровень 2 — инженерия (1–2 курс)

### Проект 03. Анализ торможения
**Задача:** найти точки начала торможения, момент отпускания, оценить trail braking.

**Что освоить:** детекция событий по порогам, поиск локальных минимумов, работа с шумом.

**Готово, когда:** для каждого поворота есть таблица «точка торможения в лучшем / худшем круге / разница в метрах».

**Фраза для интервью:** «Я могу сказать пилоту: в T1 тормози на 5 метров позже — там есть запас сцепления».

### Проект 04. Анализ шин
**Задача:** температура и давление по четырём колёсам, деградация по стинту.

**Что освоить:** fill_between, группировка по кругам, линейная регрессия деградации.

**Готово, когда:** есть вывод вида «переднее левое перегревается к 8-му кругу, давление поднять на 0.1 psi».

**Фраза для интервью:** «Шины — 80% работы гоночного инженера, и я умею читать их по логу».

---

## Уровень 3 — настройки (2–3 курс)

### Проект 05. Сравнение сетапов
**Задача:** две сессии на одной машине и трассе, разные настройки — что изменилось.

**Что освоить:** корректное сравнение (одинаковые условия!), статистика, изоляция эффекта.

**Готово, когда:** отчёт «что дала настройка X» с числами, а не ощущениями.

**Фраза для интервью:** «Я умею оценить влияние настройки объективно, а не по ощущениям пилота».

### Проект 06. Идеальный круг
**Задача:** собрать теоретический лучший круг из лучших секторов разных кругов.

**Что освоить:** разбиение на сектора, поиск минимума по группе, понимание разницы «лучший круг» и «идеальный круг».

**Готово, когда:** показан разрыв между реальным лучшим и теоретическим идеальным.

**Фраза для интервью:** «Я знаю, сколько времени лежит на трассе, но ещё не собрано».

---

## Уровень 4 — стратегия и реальные данные (3–4 курс)

### Проект 07. Симулятор стратегии
**Задача:** деградация шин, расход топлива, окно пит-стопа, сравнение 1 и 2 остановок.

**Что освоить:** регрессия, экстраполяция, сценарное моделирование, оценка рисков.

**Готово, когда:** скрипт выдаёт «оптимальная стратегия — 1 пит на 23-м круге» с обоснованием.

**Фраза для интервью:** «Я считаю стратегию в цифрах, а не "давай попробуем один пит"».

### Проект 08. Телеметрия Формулы-1
**Задача:** реальные данные F1 через FastF1 — сравнение пилотов на быстрейших кругах.

**Что освоить:** работа с внешними API, кэширование, чужие форматы данных, нестабильная сеть.

**Готово, когда:** графики F1 строятся, а в README честно описано, как обходились проблемы с доступом.

**Фраза для интервью:** «Я работал и с симулятором, и с реальной телеметрией F1 — формат разный, подход один».

## Уровень 5 — продукт (4–5 курс)

### Проект 09. Пайплайн и тесты
**Задача:** превратить набор скриптов в инструмент: конфиг, CLI, тесты, документация.

**Что освоить:** структура проекта, pytest, обработка ошибок, воспроизводимость.

**Готово, когда:** чужой человек клонирует репозиторий и запускает анализ по инструкции без вопросов.

**Фраза для интервью:** «Я пишу инструменты, которыми может пользоваться команда, а не скрипты для себя».

### Проект 10. Публичный разбор
**Задача:** статья или видео на английском: разбор одного круга от данных до вывода.

**Готово, когда:** опубликовано и есть ссылка.

**Фраза для интервью:** «Я умею объяснить сложное просто — на русском и на английском».

## Чего в портфолио быть не должно

- Папки «test123», «new», «final_final».
- Графиков без подписей осей и единиц.
- README на русском в публичном репозитории (английский — обязателен, русский можно вторым файлом).
- Данных на 100 МБ прямо в репозитории — для данных есть `.gitignore`.
- Кода, который автор не может объяснить строчка за строчкой. Это правило номер один.
